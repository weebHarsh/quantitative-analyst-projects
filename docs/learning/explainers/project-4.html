Waiting in the queue

Numbers: 96-cell study, 3 seeds, 1 hour each, synthetic market. Source: projects/04-backtester/results/sensitivity_table.md

A resting order waits in line behind everyone already there.

Each circle stands for 100 lots. A simulator has to guess how fast the line moves (queue position).

Three ways to guess when the line reaches us.

The right value of f cannot be learned from this synthetic data, so the study tries several (cancel-ahead).

A cancel takes time to arrive, so the order can still fill.

Optimistic fill assumptions flatter the result.

Profit and loss here is in the synthetic market's own units. The direction is the lesson, not the size.

One modelling choice can hide the effect of latency.

The cross rule fills an order when the market moves onto it, ignoring its place in line. About 76% of back-of-queue fills came from it, so it drowned out latency. We report both settings.

A backtest is not live profit.

This market is synthetic. The code is checked (67 C++ and 17 Python tests, 5,000 fuzz runs with no logic flaws), but the numbers show a method, not an edge. Firms hiring for live trading ask for a live record.
